# the newsletter Newsletter Draft

## Process
1. Read the most recent signal file(s) from output/research/ (current
   week and previous week if available for broader sourcing).
2. Read reference/customer-vocabulary.md.
3. Load the founder-voice skill. Load style-observations skill.
4. Draft a full newsletter issue:
   - Long-form content for PM/Designer audience
   - Written in the founder's voice per the founder-voice skill
   - Apply vocabulary guide and style-observations
   - Run the Voice Test before finalising
5. Run the validation step from CLAUDE.md: verify every source, quote,
   statistic, and attributed claim.
6. Newsletter is published under the founder's name.

## Output
Save the draft to output/newsletter/YYYY-MM-DD-newsletter.md.
Email the file to you@your-company.example via Gmail connector with
subject: '[Newsletter Draft] YYYY-MM-DD'.

## Acceptance Criteria
- Complete newsletter issue draft
- Targets PM/Designer audience specifically
- Written in the founder's voice
- All sources verified per validation step
- File saved to output/newsletter/
- Email sent to you@your-company.example
